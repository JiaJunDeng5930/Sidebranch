# 阅读体验修正验证

日期：2026-09-20。仅本地验证，没有部署。

本轮由用户明确拒绝上一版 UI 触发。设计依据与取舍见 [ADR 0003](adr/0003-reading-usability-before-spatial-detail.md)；历史行为与性能记录不作为新版可用性的证明。

## 已观察到的结果

- 正常 `/space` 使用持久化本地数据库，可创建文档与文字连接；不再用 QA 控制和压力数据作为产品预览。首次渲染的 origin hydration 错误已修复。
- 新建文档先显示标题和正文，保存位置默认折叠；实际焦点进入标题。搜索打开后直接聚焦输入框。
- 纸页只保留一条身份栏，原文 Markdown 标题继续作为正文内容。1440px 容器的稳定双页实际宽度为 640px 和 520px，间距 96px。
- 正常入口中的两字端点“假设”与另一页的跨行引文建立真实连接。色带经过页间空隙，正文高亮保持真实字符范围；原先被色带覆盖的后续文字已不受遮挡。标签放不进页间空隙时隐藏。
- AppBridge 内原生选文只出现轻量提问入口，展开后聚焦问题输入。发送后收成状态条；测试宿主写入并关联回答后显示到达提示，当前文档仍保持原文。这里验证的是官方 AppBridge 协议与本地宿主，没有在真实 ChatGPT 账号中安装或测试。
- 固定视口实测：390px 单页宽 358px、左边距 16px；768px 单页宽 640px、左边距 64px；1024px 单页宽 640px、左边距 192px。三种宽度均实际切换到另一端，旧端为 `aria-hidden`、不可交互，新端留在视口内。短文实测高度 176–178px。
- 在 267 份合成文档的窄屏空间中，逐次翻到折页组第 12/12 页，展开最后一组并选择“阅读是一种相遇”的旁读入口。顶部折页拥有预留空间，底部只保留一个另一端切换入口。QA 性能仪表移出阅读区，固定 iframe 默认不显示浮动仪表。
- 1440px 下直接激活第 80 处连接，两篇千节文档分别滚到 18948px 和 21362px，端点状态为 `range:range`。两张纸的顶部均为 iframe 内 146px，高度 570px。随后只滚动当前端到 19464px，另一端仍为 21362px；返回再前进后，两个值精确恢复为 19464px、21362px。
- 正常入口的空白区域拖动后出现“回到阅读”；可复位到阅读构图。手势提示与正文分开呈现。

## 本地性能样本

在 267 份合成文档、当前为千节长文的热态空间中，记录一次 5002.5ms 的相机拖动样本：683×837 CSS px、DPR 2，16 次实际输入。帧间隔 p95 为 17.9ms、p99 为 18.5ms、最大 18.6ms；没有超过 50ms 的长任务。双 rAF 输入代理 p95 为 30.3ms，它不是屏幕呈现延迟。样本结束时挂载 1 个正文、1227 个 DOM 节点、190 个 source spans、2 个虚拟块。

这是本地单次热态样本；不代表低端设备、冷启动或真实 ChatGPT 宿主的性能。
