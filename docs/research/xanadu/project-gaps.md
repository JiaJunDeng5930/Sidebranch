## 18 组实质对照及可观察验收

### 1. 范围几何被压成点，色带问题不是调大 stroke-width

**事实：** N 的普通评论 link 也连接声明的字符范围；S 图中有面积的面接到高亮区域；O 的算法保留首行末段、中间整行、末行前段，多边形延伸至文档外。带口随各端范围实际高度变化。

**代码／状态：部分。** `components/reader/spatial-scene.tsx:1084–1136` 已取真实 DOM Range 行矩形，但 `1102` 合并外包矩形，`1112–1123` 再取中心点。`343–347` 生成单条贝塞尔曲线；`2230–2234` 是 stroke + fill=none；`spatial-scene.css:829–847` 是 1.5/2.5px 和屏外虚线。真实内容锚定已存在，范围面积在渲染投影中丢失。`docs/space-redesign/visual-motion.md:115–116` 明确要求细线/固定薄带，是错误收窄的设计来源。

**验收：** 连接从第一行中部开始、跨三行、在末行中部结束，另一端占两行。两侧能看清真实起止范围和不同带口高度；把窗口改窄后轮廓重排，仍连接原字符。不能用两张大矩形或中心点粗线冒充范围面。

### 2. 文字高亮和外部带面必须形成连续关系

**事实：** S 高亮对象与 beams 共同移动；O 截图同色文字范围直接延续为外部桥，源码还包含文档边缘短段。官方没有规定 Sidebranch 必须照搬 10px 数值。

**代码／状态：部分。** `document-passage.tsx:32–44` 和 `passage.tsx:480–495` 用精确范围上色；外部连接独立取中心，二者没有共享范围轮廓。SVG 全屏层 `spatial-scene.css:819–826` 位于纸页上方，不能只改成大面积填充，否则可能覆盖正文选择与控件。

**验收：** 视线能从首末字符沿高亮到带口再到对侧，无可见断口或一条线穿过大片无关正文。单端滚动、缩放、虚拟段挂载时一起更新；带面上点击关系，文字上仍可正常拖选和打开正文链接。

### 3. 配色必须标清版本来源与项目语义

**事实：** S 的深色 link / 红色 transclusion、D 的灰/粉、O 的文档对色相、V 的蓝/橙不是同一套色谱。O 选中桥增加深色描边，未选中桥主要以透明填充呈现；多桥允许叠色。

**代码／状态：项目自定义，合理但未完成选中联动。** `lib/reader/relations.ts:3–25` 按五种关系设定纸面/舞台 token；这不是 Xanadu 原色。`spatial-scene.tsx:1304–1309` 按 relation 上色并存 selected；`document-passage.tsx:15–44` 没有 selectedConnectionId 输入，正文不会单独加强选中那条关系。`passage-highlights.ts:27–30` 多色重叠统一灰色，当前关系可能难辨。

**验收：** 同处三个不同关系时，逐一选择能同时辨认所选带面、两侧完整范围及关系名称；非活动重叠仍存在但不遮字。用户自建 reference 不因呈现为带面就被称为 transclusion。无需照抄 O 的色值或叠色缺陷。

### 4. 文本交叠消歧已有，连接交叉消歧与稳定追踪不足

**事实：** N/S 允许重叠；O 点击桥使用真实路径 hit-test，但交叉处最后命中覆盖前者，没有消歧菜单。这个旧限制不应照搬。

**代码／状态：部分。** `passage.tsx:554–589` 保留原始范围命中，多关系弹出选择；`593–597` 可筛选。SVG 路径 `spatial-scene.tsx:2233–2242` 各自点击，未提供交叉处候选选择。`1252–1285` 把 selected 放前面，`2221` 按该次序绘制；改成填充后所选面会先画、后续面可能覆盖它。不能忽略绘制顺序。

**验收：** 同一段五条连接、两条桥交叉，分别从文本和桥区找到目标，每次激活的 connection ID 与标签一致；选中的桥和两端始终可识别。选择一项不使其他独立关系消失或合并。

### 5. 逐条阅读连接是动作语义，不是相机平移

**事实：** D 的 c/e 沿当前 strand 中的相关 chunk 上下步进，到边界不循环；O 的 Space+上下按位置找下/上范围。两者都不等于滚轮或相机移动。

**代码／状态：缺失。** `spatial-scene.tsx:1878–1919` 只有相机键位、Escape 与 Space 手势状态，没有当前页前/后连接动作。正文有点击及多项选择，但没有完整的连接序列阅读控制。现有文档写“连续 follow”不足以规定它。

**验收：** 当前页有 12 条远近不一的关系，不使用鼠标即可按正文位置逐条检查，当前范围与另一端明确定位；到首末条有可理解的边界反馈。快捷键由项目选择，不能把新键位写成 2007 原操作。

### 6. 当前/旁读角色存在，阅读尺度仍等同

**事实：** S 明确 current 字大、companion 字小；D 源码有 1 与 0.7 的 slab 比例；O 中央大文和 1/8 来源条是另一布局，双文档模式则恢复两侧原字号，不能混写。

**代码／状态：部分。** `spatial-scene.tsx:1981–2003` 两侧共用 paperWidth，`2048` 与 `2073` 传相同宽度；`SurfacePaper:528–537` 只有位置/宽高变量，无角色尺度。`spatial-scene.css:99–130` companion 主要是 z-index、底色和阴影区别。`docs/space-redesign/visual-motion.md:23–24` 已写最大/略小，但没落实。

**验收：** 在桌面同屏可直接分清当前与旁读；旁读仍可选文和读上下文。提升旁读后角色及尺度交换，原关系仍可追溯。不要求精确复刻历史 0.7，也不牺牲可读性强制缩至 1/8。

### 7. Follow 仅定位目标，缺少两端共同阅读位置

**事实：** D Current Line 用两段对齐建立阅读位置；O 点击桥会把两侧范围放到各自窗口中央。普通自由滚动不必强制同步。

**代码／状态：部分。** `reader.tsx:984–1010` 找另一端并只传目标 focus；`attention.ts:432–446` compare 完整保留 current 的旧 focus/scroll。`passage.tsx:280–295,493–499` 能将目标首个 Range 居中，但不是整组 ranges 的共同几何定位。

**验收：** 从 A 顶部激活 A 底部—B 中部的关系，两端完整选定范围进入可比对的位置，当前页身份不改变；随后独立滚动 A 不强拉 B。跨多个 Markdown 渲染块时不要只定位第一个小 Range。

### 8. 纸面迁移与局部变形被相机动画代替

**事实：** S/作者回顾描述页面、局部高亮对象与连接一起 swoop/morph，选关系使 companion 摆入；世界相机是另一控制层。现有研究没有精确曲线/时长证据。

**代码／状态：缺失该空间行为；相机动画已具备。** `spatial-scene.tsx:1027–1057` 插值的是统一 camera Pose；`SurfacePaper:528–537` 只是新位置属性；`spatial-scene.css:99–121` 无纸页位置/局部内容变形协议。current/companion 重排不能被“400ms 相机归位”当作 morph。

**验收：** A–B 切到 A–C，能看懂 B 去哪里、C 从哪里来，连接与局部范围全过程附着；无闪现两个独立页面实例。reduced-motion 可直接到最终状态。几何方案属于待决设计，不能以研究之名预设复杂三维引擎。

### 9. 全体文档空间已建索引，外围仍只有身份壳

**事实：** S 背景保留文本页形态；O 截图两侧为完整上下文长条。不过 D 演示材料曾截断，不能把“所有原型都加载完整文档”当事实。全体文档空间、外围折页、无侧栏/总览是用户独立要求。

**代码／状态：部分／项目自定义。** `space-index.ts:277–312` 遍历 documents，含无关系及归档文档；没有成员开关，正确。`spatial-scene.tsx:587–652` 折页只含标题/版本和动作，没有真实正文。`SurfacePaper` 只渲染 current/companion（2033–2081）；不能把现有折页声称为完整外围文档表现。

**验收：** 相关/无关/归档文档均能从纸场找到，展开折页获得该文档内容上下文，再旁读和提升；无需额外目录、总览、加入空间开关。允许按需加载与虚拟化，但不以一行标题永久替代用户要求的文档形态。折页是项目延伸，不能归功于原图。

### 10. 双向关系保留，但旁读继续跟随受当前根限制

**事实：** N 双向追踪保留两端角色；S companion 可以成为 current 后继续。双向不等于无方向，也不要求每条桥都有箭头。

**代码／状态：部分。** `model.ts:117–124` 保留独立 ID、from/to；`reader.tsx:993–999` 仅接受与 currentRevision 相连的连接。`document-passage.tsx:34–36` 会给旁读自己的关系上色，但若 B 旁读上的 B–C 不含 A，激活会 return。与旧 `docs/xanadu-interaction.md:12` 承诺“在 companion 上继续跟随”存在缺口。

**验收：** A 当前、B 旁读时激活 B–C，有明确可见的继续阅读结果；不能静默无响应。具体是先提升 B 再带入 C，或明确要求提升，由全局交互决策确定并与控件措辞一致。A–B 反向追踪仍显示同一 connection ID 和准确版本。

### 11. 历史返回应与沿关系换页分开

**事实：** D s/f 沿连接换 strand，没有历史栈；S 将 companion 设为 current 也不自动证明浏览器 Back 行为。Sidebranch 的历史是产品扩展。

**代码／状态：已满足基本分离／项目自定义。** `attention.ts:448–461` promote；`476–503` history 与滚动快照分开。`reader.tsx:1024–1032` 明确 history 入口。`spatial-scene.tsx:2121` 起有返回叶。这些不能再称“原型按键复现”。

**验收：** A→旁读B→提升B→旁读C，然后 Back 恢复 B 的上一阅读快照；沿 B–A 关系是新导航，不等于 Back。恢复两边版本、范围、滚动与相机；返回叶不删除任一文档。

### 12. Link 身份已经正确，不要为画带面扩建完整 transclusion 后端

**事实：** N 区分不同内容的 link 与同一内容身份的 transclusion；普通 link 也可以有面积表现。O 仅展示 transclusions 不是整个 Xanadu 只支持引用。相同字符串不自动产生共享身份。

**代码／状态：已满足 link 身份边界；transclusion 缺失但不属于本次视觉纠正必需项。** `model.ts:110–124` 是 Anchor + Connection；`commands.ts:209–216` link 独立于 question/answer。现有没有 source identity。`docs/xanadu-interaction.md:15` 的区分正确，`visual-motion.md:115–117` 将该语义差别绑死为细线/双线则过度简化。

**验收：** 现有五种 link 改成范围带面后仍保留原连接 ID、from/to、relation、label。AI 复述和手工复制只称 link；不给其来源身份标记。未来 transclusion 是另一个明确授权的模型问题。

### 13. 精确历史版本已保护，跨版本幸存内容仍有边界

**事实：** N 描述稳定字符身份及修改后 surviving spans；可拆为多个范围，不等于纯文本重找。S Fig.5 不同字号使等长内容占不同高度。

**代码／状态：已满足不可变端点；不具备 Xanadu 完整跨版本继承。** `commands.ts:203,207–209` edit 新建 immutable revision，link 保存 UTF-16 范围与 quote。`scene:1087–1096` 匹配精确 revision；`space-index.ts:88–92` 强调目标版本。不要因为旧文档讲“长期保持连接”就声称已实现字符幸存模型。

**验收：** 编辑 A 得到 v2，旧连接仍打开 A v1 的准确文字；可明确选择最新版但不静默搬锚点。色带像素高度随两端布局独立变化；句子相同不能推断共享身份。

### 14. 屏外/虚拟化端点要保留身份，不能伪装为精确范围

**事实：** N 要求实际内容仍是端点；O 无完善逐纸面裁剪，不可拿原型瑕疵当标准。屏外折页及“待定位”是 Sidebranch 自己的表达责任。

**代码／状态：部分。** `scene:1111–1134` 仅当 union 与视口完全不交才设 clipped；部分范围露出时仍 exact。`1138–1200` 对虚拟 gap/折页退成点并标 paperEdge；`CSS:845–847` 以虚线表达，`scene:2247` 有“待定位”标签。改带面需区分完整、部分可见和未挂载三种几何，不能以外包矩形相交证明范围完整。

**验收：** 上下滚动使范围只剩末行时，显示可见部分和继续位置；完全屏外时出现明确入口，激活恢复原范围。折页是导航代理而非假造范围宽度；绝不因缺 DOM 改保存锚点。

### 15. Hover、控件密度和时间值属于现代设计

**事实：** 已查 O 主事件没有 hover，S 手册也不能支持 hover 推断；V 的点击开关有文献证据。没有研究证明 160/280ms 或某种缓动是“原设计”。

**代码／状态：项目自定义、部分落实。** `scene:609–612,1543–1560` 折页 pointer/focus 统一延迟；`2264–2296` 只保留选中/精确连接前三个标签且短标签都是“连接”，详情 hover/focus 才出现（CSS:886–907）。`visual-motion.md:123–126,269` 对锚点 hover 和焦点及时显现的承诺并非全部由当前实现支持。

**验收：** 未选连接不铺满按钮；聚焦或选中后可获得明确关系、两端标题/版本。鼠标移动不改 current；键盘不依赖鼠标停留；拖选时不会被预览打断。密度/时间需实际试用决定，报告不得虚构历史依据。

### 16. 窄屏与键盘是完整产品要求，不能复制旧桌面限制

**事实：** 原型资料不足以给出现代触控或窄屏规范；用户同时要求网站与 ChatGPT App UI。

**代码／状态：部分／项目自定义。** `CSS:964–1023` 620px 以下纵向流、取消 perspective；`scene:2232–2242` 路径有键盘激活，折页有原生按钮；`1887` 窄屏不处理相机键。纵向相隔很远的两范围不可能总同屏，当前没有独立的逐连接阅读动作。

**验收：** 390px 与嵌入 App 高度受限时仍能从关系获得两端身份、到达相应范围并返回当前位置；不横向溢出、不使浮层吞正文。仅键盘完成选择关系、旁读、提升、历史返回、选文提问；窄屏允许另一种投影，但不丢关系语义与文档访问。

### 17. 异步阅读与 AI 工作流应保留，视觉更新不能抢焦点

**事实：** D 只读硬编码 demo 不含这组能力；不能据此删减用户明确要求的 AI 选文问题、独立答案文档、独立连接、统一文件操作。

**代码／状态：已有明确边界。** `reader.tsx:899–981` 请求 ID + attention epoch 防迟到旁读覆盖；`663–691` 答案到达只通知/缓存，`693–698` 显式 open 才导航。`commands.ts:199–218` cat/write/edit、ask、answer、link 各自独立；`workspace.tsx:5` 与 `app-ui/main.tsx:239` 共用 Reader。

**验收：** A–B 请求未完又选 A–C，迟到 B 不替换 C；等待答案时继续读和拖选，答案到达保留选区/current/相机；用户激活答案才并读。网站和 ChatGPT App 都能完成保存问题→写答案文档→关联答案→建立文字连接，任一步失败不冒称其他步骤完成。

## 覆盖主要细节的操作验收序列

准备 A/B/C/D 四篇 Markdown 与长文本：A 中一个跨首末半行的多行范围；B 对应范围采用不同换行；同一 A 范围有 A–B、A–C 等多条关系；另有 B–D；保存旧版 A v1 后编辑 v2。另备超过边缘和可见连接预算的文档/关系。准备只是一组验收材料，本轮未创建或运行。

1. 桌面打开 A，观察当前文本、外围完整文档形态与折页；无侧栏、总览或成员勾选。通过折页访问无直接关系的文档，确认全体空间可达。
2. 激活 A–B，检查主次尺度、两端实际字符范围、两端对齐、带面轮廓和高亮连续性、关系名/版本；不把普通 link 标为来源共享。
3. 在同一文本范围和交叉带区逐一选 A–B/A–C，核对 connection ID 与双端反馈；用上一/下一关系动作走到边界，再继续普通滚动。
4. 仅滚 A，令端点部分越界、完全越界、进入虚拟 gap；观察带面及边缘入口，再定位回来。缩窄桌面窗口，使两端不同地重排；校验内容身份不变。
5. 平移、缩放、转向后连续切换 A–B/A–C，观察纸页去向与范围联动；中途反向操作和 reduced-motion 各一次，最终场景一致。
6. 在旁读 B 激活 B–D，验证明确结果；提升 B，然后沿 B–A 返回与执行 Back 各一次，检查不同语义和滚动/版本恢复。
7. 从旧连接打开 A v1，主动切最新版 v2，确认没有静默迁移旧锚点。复制相同句子不自动产生 transclusion 身份。
8. 依次鼠标 hover、键盘 focus、拖选同一范围，确保预览不导航、不抢选区；不触鼠标完成关系选择、旁读、提升、返回和选文问题。
9. 在 390px 网站及 ChatGPT App UI 重复 2/4/6/8；关系两端可能不同时可见，但必须可往返并保留身份、上下文与焦点。
10. 制造迟到 B 请求、随后选 C，再让 B 返回；等待 AI 回答期间继续阅读/选择。验证迟到请求与答案通知不抢焦点，答案仍是独立文档、答案关联与文字连接独立。
11. 长文和超预算关系下重复滚动、连接序列、选区和折页；检查未渲染对象仍可达、选中关系优先、真实性能和响应。记录运行证据后才能宣布实现通过。
